# Duskline One Star

A deadpan one-star review of an everyday essential, for the make.fun
bounty **"One-Star Review of Something Essential"**
(`u-0xb3e689-one-star-review-of-something-essential-c7234629`).

## Entry

> One star for gravity. Works fine until you drop your phone
> face-down, then suddenly it is the hardest-working force in the
> universe.

132 characters — within the 160-character limit, single line.

## How it works

`main.py` (Python 3.13, standard library only, deterministic, no
network) writes the review text to `$MAKEFUN_OUTPUT_DIR/entry.txt`
and nowhere else. Run locally with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
